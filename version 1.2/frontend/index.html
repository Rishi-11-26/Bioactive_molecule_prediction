About the project

Science behind BioPredict

An end-to-end cheminformatics pipeline — from curated ChEMBL bioassays to an explainable, deployable web service.

Curated dataset

COX-2 bioactivity records from ChEMBL (CHEMBL230), deduplicated, standardised and labelled using an IC50 activity threshold.

Morgan fingerprints

Each molecule becomes a 2048-bit ECFP4-style vector capturing circular atom environments of radius two.

XGBoost classifier

Gradient-boosted trees selected after benchmarking against ANN, SVM, RBF, Random Forest and Naive Bayes.

Explainability

Feature importances are mapped back to fingerprint bits and atoms, revealing the fragments behind each decision.
